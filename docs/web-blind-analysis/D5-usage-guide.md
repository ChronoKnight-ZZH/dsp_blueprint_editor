# D5 · 模式使用说明 v1.0（一页）

模式名：**Web 盲分析 · 亮执行**（Web-Blind-Analysis Mode）
一句话：让零文件权限的 Web AI 只做"看料下菜"的深度分析，让有权限的执行方零思考照单施工，从而把探索型 token 消耗压到最低。

---

## 1. 角色分工

| 角色 | 权限 | 职责 | 交付物 |
|---|---|---|---|
| 分析端（Web AI） | **无读文件、无执行命令** | 只吃你粘贴的内容，产出分层修改方案 | D1 |
| 你 | 运输层 + 路由开关 | 粘贴卡片与片段；声明走哪个出口 | — |
| 执行端（本地/IDE Agent） | 有文件读写、有命令 | 只按索引表编号落地，失配即停并回传 | D3 |

## 2. 每次开工的最小粘贴顺序

```
① D1 完整版（或 原提示词 + D1补丁版）  ← 每个新对话都要
② D2 项目卡片                        ← 一次填好，长期复用（卡片态）
③ 本次涉及的原文片段                 ← 只贴要改的文件 + 其调用方/被调用方
④ 需求一句话 + 成功标准
```
不贴 ② → 自动进【裸态】，分析端会首行声明并给你"补 3 项可升卡片态"清单。

## 3. 触发词表（切换出口）

| 你说 | 得到 |
|---|---|
| `转交Agent` / `给Agent` / `交给执行Agent` / `出方案` | **出口A**：索引表 + 详层 + 停止契约 + 回传协议（给 D3 用） |
| `人工执行` / `给我代码` / `我自己改` / `出施工单` | **出口B**：人工施工单（D4 结构，可整文件覆盖） |
| 什么都不说 | **默认出口A** |
| `双出口` | 两份都出（长度翻倍，非必要不用） |
| `展开 A-03 A-07` | 只展开指定编号的详层（防截断，省 token） |

## 4. 门禁（何时才出代码）

确认前：**零代码**（含片段/补丁/配置/脚本/伪代码），只允许提问、复述、更新备注栏。
解锁钥匙：你确认「需求理解摘要 + 方案分点目标 + 阶段任务清单 + 备注栏」。
阶段门：每进一个阶段先给任务清单，未达完成标准不进下一阶段。

## 5. 备注栏（交接清单）

7 类固定：【已确定】【待确认】【需 Agent 确认】【后续解决】【需修改】【不需改动】【假设与风险】。
频率：**每轮 Δ 增量 + 阶段边界/最终报告全量**。
出口A 尾部附**完整 7 类**（你选定 B-3①）。
执行端注意：备注栏只是上下文，**只有【需修改】的编号才可执行**（K11）。

## 6. 出错了怎么办

| 现象 | 含义 | 动作 |
|---|---|---|
| 大量「失败:未找到」 | 你粘贴的原文已过时 | 索要该文件全文，重出一版方案（别继续盲改） |
| 「失败:多处匹配」 | 锚点签名不唯一 | 把命中处 ≤10 行回传，分析端加宽窗口重出该点 |
| 对账数 ≠ 总点位 | 执行端漏做 | 整批重跑，不要只补缺项 |
| 出现 `UNAUTHORIZED` | 执行端越界 | 要求回滚，并把教训写进卡片 [6] 禁改边界 |
| 方案出现无 `[E1]~[E3]` 的事实断言 | 分析端幻觉 | 立即质询并要求降级为 [E5]；这是本模式最危险的失效 |

## 7. 轮次与成本控制

- 1 轮方案 + 最多 2 轮批量修订；仍失败 → 索要全文。
- 批量回传：跑完再回，禁止挤牙膏式逐条提问。
- 详层默认折叠，指定编号才展开。
- 全量替换硬上限 400 行；只粘片段一律局部替换。

## 9. 本模式无法消除的残余风险（诚实声明）

1. 纯 Web 端是**提示词级软约束**，不是权限级硬门禁——模型理论上仍可能谎称读过文件。防线是证据码制度：无来源的断言必须显式可见，你要抽查。
2. 分析端**无法自证**：所有回归验证必须发生在执行端或你手里。
3. 方案精度上限 = 你粘贴内容的完整度与新鲜度。粘贴越少越省，越容易失配，往返越多越贵——卡片态是唯一的平衡点。
