# D5 · 模式使用说明 v1.1（一页）

模式名：**Web 盲分析 · 分层交付**（Web-Blind-Analysis Mode）
一句话：零文件权限的 Web AI 基于**粘贴片段的证据链**做初步分析，默认只出 **E0 大概方案**（点位+方法+边界+验收，零代码）；源代码实现交给有项目权限的执行 Agent；用户要代码时再按编号展开 E1/E2。

## 1. 角色分工（v1.1 成本翻转后）

| 角色 | 权限 | 职责 | 提示词 |
|---|---|---|---|
| 分析端（Web AI） | 无读文件、无执行 | 证据链约束的初步分析 → E0/E1/E2 分层交付 | D1 |
| 你 | 运输层 + 路由开关 | 粘贴卡片/可选片段；声明档位 | — |
| 执行端（本地/IDE Agent） | 有文件读写与命令 | **白名单内有限分析**：核实 M5 → 写码 → 按 M4 验收回传 | D3 |

为什么翻转：让 Agent 读本地一个文件，远比"你把它贴进 Web、再让网页端复述一遍"便宜。探索应发生在探索便宜的一方；网页端的价值是**方向、边界、验收**，不是复述代码。

## 2. 每次开工的最小粘贴顺序

```
① D1 完整版（或 原提示词 + 补丁版）   ← 每个新对话都要
② D2 项目卡片                        ← 一次填好长期复用；不贴则裸态告警
③ 需求一句话 + 成功标准
④ （可选）想升精度的文件片段          ← β 规则：贴了即挂 [E1] 升方法级；不贴走意图级+核实清单
```

## 3. 触发词表 v2（档位路由）

| 你说 | 得到 |
|---|---|
| 未声明 / `出方案` / `转交Agent` | **E0 大概方案**（默认；配 D3 交执行 Agent） |
| `详细方案` / `精确方案` / `给我可套用的补丁` | **E1** = E0 + 锚点 + 改后完整内容（须有原文证据，按编号派生） |
| `人工修改` / `给我代码` / `我自己改` | **E2** = E0 编号展开为人类步骤 + 该点源代码 |
| `展开 E0-03` | 只对指定编号深展开 |
| `双档` | E0+E1 同出（长度翻倍，非必要不用） |

升级链编号互认：`E0-xx → A-xx → B-xx`，不得漂移。

## 4. 门禁与证据链（何时才出代码）

- 需求确认前：零代码。E0 天然零代码，方向获认可即可交付；E1/E2 仍须过确认钥匙。
- 方法点档位由证据决定（§4.4）：**方法级**（贴过片段）/ **意图级**（只有需求，具体形态一律"以实际代码为准"进 M5）/ 禁止档（无证据写具体签名/字段 = 幻觉，头号违规）。
- 每点位必含：M3 边界 / M4 可判定验收 / M5 核实清单。E0 尾部固定"粘贴建议 ≤3 项"。

## 5. 备注栏（交接清单）

7 类固定；每轮 Δ + 阶段边界全量；E0/E1 尾部附完整 7 类。
执行端只认【需修改】编号；M5 先核实后施工；核实与假设冲突 → 以实际代码为准并回传"偏差"。

## 6. 出错了怎么办

| 现象 | 含义 | 动作 |
|---|---|---|
| 回传"偏差"列很多 | M5 低估了现状复杂度 | 按粘贴建议补贴关键文件，或对该编号升 E1 |
| 某编号反复「需确认」 | M3 边界与实现真冲突 | 你裁定；不要指望 Agent 猜 |
| 同编号 2 次验收不过 | 触发返工上限 | 停 → 该编号出 E1 或转人工（E2） |
| 对账数 ≠ 总点位 | 执行端漏做 | 整批重跑 |
| `UNAUTHORIZED` | 执行端越界 | 回滚；教训写进卡片 [6] |
| 意图级点位写出具体字段名 | 分析端幻觉方法点 | 质询并要求降级 [E5]（v1.1 头号失效） |

## 7. 轮次与成本控制

- 1 轮 E0 + 最多 2 轮批量修订；仍失败 → 索要全文 / 出 E1。
- 批量回传（SUMMARY(E0) 对账式），禁止挤牙膏。
- E0 详段每点 ≤6 行硬约束；详谈按编号展开。
- E1/E2 沿用粒度规则：片段输入必局部（不可覆盖）；整文件按 150/400 阈值路由（卡片可覆盖阈值）。

## 9. 残余风险（诚实声明）

1. 软约束≠硬权限：模型仍可能谎称读过；防线=证据码可追责 + 你抽查。
2. 分析端无法自证：验证全部发生在执行端/你手里（M4 验收制就是这个兜底）。
3. E0 的方向正确性依赖证据链质量：卡片越准、贴得越对，意图级点位越少、Agent 返工越少。
4. v1.1 新风险：把"方法级"当"精确级"用——E0 不是图纸，别指望零返工；它的承诺是**方向对、边界清、验收硬**，配合 ≤2 轮修订封顶。
