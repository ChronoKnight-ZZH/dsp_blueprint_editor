# 传送带选中续建功能阶段任务计划

## 1. 需求目标

在编辑器建造模式下，支持用户：

1. 鼠标悬停已建成传送带的单个节点时显示高亮。
2. 左键选中该节点作为新传送带的 A 点。
3. 从已有传送带节点继续预览、建造新的传送带。
4. 新传送带继承选中节点的区域、高度和起点位置。
5. 从已有传送带末端继续建造时，自动复用末格并正确串联。
6. 保持现有传送带连接拓扑规则，禁止普通传送带中间节点产生非法分叉。

目标视觉：

```text
已有传送带节点（悬停高亮）
        ↓ 左键确认
白色六边形节点 + 白色连线预览
        ↓ 第二次点击
新传送带接入已有传送带
```

## 2. 当前代码基础

| 能力 | 当前实现 | 复用方式 |
| --- | --- | --- |
| 建筑/传送带拾取 | `BlueprintEditor.vue` 的 `pickBuilding` / `pickBuildingHit` | 扩展返回的传送带命中信息 |
| 空间碰撞拾取 | `src/lib/core/buildBVH.ts` | 第一阶段不改 |
| 传送带 A/B 点击状态机 | `BlueprintEditor.vue` 的 `beltStart` / `commitBeltLine` | 增加传送带节点来源状态 |
| 起点高度继承 | `beltStartZ` | 直接继承选中传送带的 `localOffset[0].z` |
| 白色六边形预览 | `beltPreviewMesh` / `beltEndMarkerMesh` / `beltLinkMesh` | 直接复用 |
| 高度坡度生成 | `buildBeltLine` / `slopeProfile` | 不新增交互算法 |
| 末格复用与撤销 | `CreateBeltLineCommand` | 第一阶段复用现有逻辑 |
| 高度层占用 | `occupancyKey` / `zLayer` | 支持同格不同高度的传送带 |

当前已有一个重要限制：`CreateBeltLineCommand` 只允许复用没有下游连接的已有末格；命中已有中间格时会截断，避免普通传送带产生分叉。

## 3. 功能边界

### 3.1 第一阶段必须实现

- 传送带节点悬停高亮。
- 传送带节点左键设为 A 点。
- A 点继承已有传送带的：
  - `areaIndex`
  - `localOffset[0].z`
  - 网格位置
  - 平面朝向
- 从已有末格继续铺设。
- 新传送带预览支持现有直线、L 形、坡度和高度提示。
- 中间节点不能直接产生分叉，并给出明确提示。
- 右键取消 A 点后清除高亮确认状态。
- 撤销后已有末格的连接字段恢复。

### 3.2 第一阶段不实现

- 从传送带中间节点插入新线路。
- 从中间节点反向重排原有线路。
- 普通传送带分叉。
- 整条传送带链路高亮。
- 修改 library viewer 的传送带选中接口。
- 修改传送带真实渲染材质。
- 支撑柱、地基和额外建设动画。

## 4. 交互状态设计

### 4.1 悬停状态

新增编辑器内部状态：

```ts
const beltHover = ref<{
    index: number;
    cell: { x: number; y: number };
    z: number;
} | null>(null);
```

鼠标移动时：

1. 使用现有 BVH 取得建筑索引。
2. 判断命中对象是否为传送带。
3. 转换到该传送带所属区域的局部坐标。
4. 保存传送带索引、格坐标和高度。
5. 更新黄色/高亮覆盖层。

鼠标离开画布、退出建造模式或切换建筑时清除该状态。

### 4.2 已确认 A 点状态

在现有状态基础上增加：

```ts
let beltStartBuildingIndex: number | null = null;
```

已有状态继续保留：

```ts
let beltStart: { x: number; y: number } | null;
let beltStartPort: BeltPortEnd | null;
let beltStartZ: number;
```

状态含义：

| 状态 | 含义 |
| --- | --- |
| `beltHover` | 当前鼠标悬停的传送带节点 |
| `beltStart` | 新线路的平面 A 点 |
| `beltStartBuildingIndex` | A 点来源是否为已有传送带 |
| `beltStartPort` | A 点来源是否为建筑传送带口 |
| `beltStartZ` | 新线路起点高度 |
| `placement.beltZ` | 新线路终点/建造高度 |

三类 A 点来源：

1. 建筑传送带口：继承端口高度并绑定端口。
2. 已有传送带节点：继承节点高度，不设置建筑端口绑定。
3. 空白网格：使用当前建造高度作为起点和终点。

## 5. 高亮实现方案

### 5.1 推荐方案：编辑器独立覆盖层

在 `BlueprintEditor.vue` 增加一个独立的高亮 Mesh，不修改真实传送带材质。

原因：

- 当前真实传送带由 `src/lib/core/buildBuildings.ts` 统一构建。
- 多个节点可能共用材质或合并几何。
- 直接修改真实材质会影响其他传送带。
- 编辑器高亮属于 Vue 交互层，不应扩散到 library renderer。
- 独立覆盖层可以复用现有白色六边形几何和矩阵计算。

高亮对象建议包含：

```text
黄色六边形外圈
黄色/白色中心六边形
必要时增加轻微高度抬升
```

矩阵使用：

```ts
calcBuildingTrans(PLANET_RADIUS, b.value.pos, belt)[0]
```

再叠加现有的 `beltLift`，确保高亮适配球面、yaw 和 belt z。

### 5.2 高亮层级

第一阶段只高亮单个悬停节点：

```text
鼠标移动 → 单节点黄色高亮
左键确认 → 节点进入 A 点确认状态
移动鼠标 → A 点保持确认高亮，新线路使用白色预览
```

整条传送带链路高亮作为后续任务，不在第一阶段加入。

## 6. 连接规则

### 6.1 从末格继续建造

已有线路：

```text
A → B → C（C 为末格）
```

新建线路：

```text
C → D → E
```

执行步骤：

1. 识别 C 的 `outputObjIdx < 0`。
2. 新线路构造时将 C 作为可复用节点。
3. `CreateBeltLineCommand` 将 C 的 `outputObjIdx` 改为新线路首个节点。
4. 撤销时恢复 C 原来的连接字段。

该流程复用现有 `CreateBeltLineCommand`，不新增连接命令。

### 6.2 从中间格继续建造

已有线路：

```text
A → B → C → D
```

从 B 继续会形成：

```text
       → 新线路
A → B
       → C → D
```

第一阶段禁止此操作。

判断条件：

```ts
selectedBelt.outputObjIdx >= 0
```

处理方式：

- 不提交非法连接。
- 保留当前 A 点或取消本次操作，需在实现时统一。
- 显示提示：

```text
只能从传送带末端继续建造
```

### 6.3 不同高度

选中传送带后：

```ts
beltStartZ = selectedBelt.localOffset[0].z;
setBeltZ(beltStartZ);
```

之后按 ↑/↓ 修改终点高度，继续复用现有 `slopeProfile`：

```text
起点传送带高度 → 自动爬坡 → 终点建造高度
```

仍遵守：

- 第一个点水平建造。
- 最后一段水平建造。
- 终点节点只有一条带。

## 7. 分阶段任务计划

### P0：现状核对与交互契约

任务：

- 核对 `pickBuildingHit` 对 belt 节点的命中结果。
- 核对高层传送带命中时的 z 计算。
- 核对末格、中间格的连接字段。
- 固定第一阶段只支持末格续建。

产出：

- 传送带命中数据结构。
- A 点来源状态定义。
- 中间格禁止分叉的提示语。

验收：

- 能明确区分空白网格、建筑口、已有传送带节点。

### P1：传送带节点悬停高亮

修改：

- `src/components/BlueprintEditor.vue`

任务：

- 新增 `beltHover`。
- 新增高亮六边形覆盖层。
- 扩展 `onPointerMove`。
- 在 `onMouseLeave` 和模式切换时清理高亮。

验收：

- 鼠标移动到已建传送带单格时，该格高亮。
- 移到空白处后高亮消失。
- 高层传送带高亮位置正确。
- 不影响建筑、分拣器、地基预览。

### P2：选中传送带节点作为 A 点

修改：

- `src/components/BlueprintEditor.vue`

任务：

- 新增 `beltStartBuildingIndex`。
- 第一次左键命中 belt 时记录节点。
- 继承 `beltStartZ`。
- 记录区域和局部网格坐标。

### P3：从传送带末格继续预览

- 复用白色六边形和白色连线。
- 确保预览不重复产生错误的起点端圈。

验收：

- 新线路预览从旧带末格开始。
- 起点首段保持水平。
- 预览高度和实际提交高度一致。

### P4：末格连接提交与撤销

修改：

验收：

## 9. 风险与处理

| 风险 | 处理 |
| --- | --- |
| 高层传送带被地面遮挡导致拾取不准 | 使用现有 BVH 命中并保留命中高度，必要时增加 belt 专用拾取盒 |
| 传送带实际 ribbon 与 BVH 选择盒大小不一致 | 第一阶段沿用现有选择盒；后续再做精确 segment picking |
| 中间节点产生非法分叉 | 第一阶段明确禁止，只允许末格续建 |
| 选中节点高度与 `placement.beltZ` 不一致 | A 点时同步 `beltStartZ` 和 `placement.beltZ` |
| 坡度生成节点数增加 | 继续使用 `BELT_PREVIEW_CAP`，提交前增加长度上限保护 |
| 预览端圈与已有末格重叠 | 已有节点使用选中高亮，新增部分从下一个可建节点开始显示 |
| 场景重建导致高亮索引失效 | 场景重建后校验索引；越界立即清理选择状态 |

## 10. 第一阶段验收标准

完成 P1~P5 后，必须满足：

1. 建造模式中，鼠标悬停传送带单格可高亮。
2. 左键点击后，该格成为 A 点。
3. A 点高度继承已有传送带。
4. ↑/↓ 可以修改新线路终点高度。
5. 新线路预览和提交都使用同一套坡度逻辑。
6. 从传送带末格继续时，旧带与新带正确串联。
7. 从中间格继续时不会生成非法分叉。
8. 右键取消、退出模式、删除、撤销后，不残留高亮或旧索引。
9. 所有已有测试继续通过。

## 11. 后续扩展：中间节点插入

如果后续需要支持从任意中间节点向前/向后建造，需要单独设计“线路插入命令”，不能直接复用末格追加逻辑。

需要处理：

- 找到当前节点的上游和下游。
- 选择连接方向。
- 修改上游节点的 `outputObjIdx`。
- 将新线路接入原下游。
- 维护 `outputToSlot`、`inputObjIdx` 和端口方向。
- 保存全部旧字段用于撤销。
- 防止形成环路和多下游。

这部分建议作为独立阶段 P7，不与第一阶段的末格续建混合实现。
