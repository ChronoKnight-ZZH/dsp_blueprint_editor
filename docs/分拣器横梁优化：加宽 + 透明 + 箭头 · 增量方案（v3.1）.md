# 分拣器横梁优化：加宽 + 透明 + 箭头 · 增量方案（v3.1）

> 本方案是 v3 的增量补丁，只动分拣器横梁，不改传送带、货物、拾取、蓝图数据。v3 的 G1~G11 全部保持有效。

---

## 1. 变更摘要

| 项 | v3 现状 | v3.1 |
| --- | --- | --- |
| 横梁几何 | `BoxGeometry(0.15, 0.06, 1.0)` | `BoxGeometry(0.30, 0.06, 1.0)`（宽度翻倍，长度仍靠实例 `scale(1,1,len)`） |
| 横梁材质 | 不透明 `MeshLambertMaterial` | `InserterMaterial`：`transparent: true, opacity: 0.62, depthWrite: false` |
| 横梁顶面 | 纯色 | 沿 `-z`（与货物同向）滚动的人字箭头，周期 `0.5` 世界单位 |
| 帧循环 | 写 `cargos.cargoMove` / `belts.cargoMove` | 再写 `inserters.cargoMove` |
| Draw Call | 分拣器横梁 1 个 | 仍 1 个（透明与箭头都在同一材质内完成） |

## 2. 目标

| 编号 | 目标 | 关联 | 验收 |
| --- | --- | --- | --- |
| **G12** | 分拣器横梁宽度 ≥ 2× 原值，顶面能容纳可辨识箭头 | R5 视觉 | A-8 |
| **G13** | 横梁半透明，能透过横梁看到下方货物，货物与横梁仍可区分 | R5、G4 | A-9、D-1 复核 |
| **G14** | 横梁顶面箭头沿臂长滚动，方向与货物滑动一致，跨臂长周期稳定 | R2 延伸 | A-10、B-3 复核 |

非目标：横梁侧面箭头（厚度仅 0.06，不可见）、逐实例透明度、横梁支撑柱（v3 Q6 仍不做）。

## 3. 原理

### 3.1 加宽

只改几何 `x` 尺寸，实例矩阵不变（仍 `scale(1,1,len)`）。`offset = T(0,0,-0.5)` 保持，臂的端点语义不变。拾取盒来自 `inserterTrans`，**不受影响**（v3 §3.3）。

### 3.2 透明

- `transparent: true` + `opacity: 0.62`：`MeshLambertMaterial` 的 `diffuseColor.a` 与 `instanceColor`（元数据色）相乘，颜色自然变淡，符合「半透明横梁」预期。
- `depthWrite: false`：避免横梁自身写深度导致后方横梁被剔除。**已知限制**：同一 `InstancedMesh` 内实例不按距离排序，密集分拣器且视角使近梁先绘制时，远梁可能叠在近梁之上；横梁细长、重叠概率低，`opacity 0.62` 下瑕疵不显著。若实测不可接受，回退 `depthWrite: true`（代价是近梁先绘制时远梁被完全剔除）。
- 透明物体默认在不透明物体（货物、条带）之后渲染，无需手动 `renderOrder`；如遇排序异常可显式 `mesh.renderOrder = 1`。

### 3.3 箭头（关键：臂长是逐实例的）

传送带箭头能用 `position.z / BELT_LEN + 0.5` 是因为段长恒定。横梁长度 `len` **逐实例不同**，因此：

```
armLen = length(instanceMatrix[2].xyz)          // 从实例矩阵 z 轴提取，零额外 attribute
worldZ = (position.z + 0.5) * armLen            // 0 .. armLen
phase  = fract(worldZ / INSERTER_ARROW_PERIOD + cargoMove)
```

- 方向：`+ cargoMove` 与传送带一致，等相位线向 `-z`（臂尖）移动，与货物 `transformed.z -= cargoMove * d` 同向。
- 周期：`INSERTER_ARROW_PERIOD = 0.5` 世界单位，横梁上约 `len / 0.5` 个箭头；`len` 为 1 格（1.2578）时约 2.5 个箭头，视觉密度与传送带（每格 1 个）接近。
- 顶面 mask：`step(0.5, normal.y)`，只画顶面；侧面仅 0.06 高，不画。
- 宽度方向：`position.x` 归一化到 `±INSERTER_BEAM_WIDTH/2`，用于人字斜边与边缘淡出。
- 箭头区提高 alpha：`diffuseColor.a = mix(a, 0.95, mask)`，使箭头在 0.62 透明梁上仍清晰。

## 4. 接口设计（新增 `src/inserter.ts`）

```ts
import { Color, InstancedMesh, MeshLambertMaterial, BoxGeometry } from "three";

export const INSERTER_BEAM_WIDTH = 0.30;       // 原 0.15 → 翻倍
export const INSERTER_BEAM_THICKNESS = 0.06;
export const INSERTER_OPACITY = 0.62;
export const INSERTER_ARROW_PERIOD = 0.5;      // 世界单位
export const INSERTER_ARROW_COLOR = new Color(0x2f3438); // 深灰，在透亮横梁上对比最好

class InserterMaterial extends MeshLambertMaterial {
    readonly cargoMoveUniform: { value: number };
    readonly arrowColorUniform: { value: Color };
    onBeforeCompile(p: WebGLProgramParametersWithUniforms): void;
    customProgramCacheKey(): string;           // "dsp-inserter-arrow-v1"
}

export class Inserters extends InstancedMesh {
    declare geometry: BoxGeometry;
    declare material: InserterMaterial;
    constructor(count: number);                // BoxGeometry(W, THICKNESS, 1.0)
    public get cargoMove(): number;
    public set cargoMove(v: number);
}
```

> `customProgramCacheKey` 必须与 `BeltMaterial`、`CargoMaterial` 不同（v3 GL6 同理）。

## 5. `buildInserters` 改动

```ts
const buildInserters = (inserters: BlueprintBuilding[]) => {
    const mesh = new Inserters(inserters.length);
    const offset = new Matrix4().makeTranslation(0, 0, -0.5);
    const temp = new Matrix4(), trans = new Matrix4(), cargoTrans = new Matrix4();

    for (let i = 0; i < inserters.length; i++) {
        const b = inserters[i];
        const len = inserterTrans(transforms[b.index], trans);   // 不改 inserterTrans

        // ① 货物：基础姿态下移（必须在 trans 被 multiply 前 copy）
        cargoTrans.copy(trans).multiply(temp.makeTranslation(0, -INSERTER_CARGO_DROP, 0));
        addCargo(cargoTrans, CARGO_COLOR, len);

        // ② 横梁：抬高 + 缩放 + 端点偏移（与 v3 相同，只是几何更宽）
        trans.multiply(temp.makeTranslation(0, INSERTER_BEAM_EXTRA_LIFT, 0));
        trans.multiply(temp.makeScale(1, 1, len));
        trans.multiply(offset);

        mesh.setMatrixAt(i, trans);
        mesh.setColorAt(i, colorOf(b.modelIndex));   // 元数据色，透明后自然变淡
        modelRef[b.index] = { mesh, instance: i };   // 拾取/投影语义不变
    }
    mesh.instanceMatrix.needsUpdate = true;
    mesh.instanceColor!.needsUpdate = true;
    return { mesh };
};
```

`buildBuildings` 返回体加 `inserterMesh`；`AllBuildings` 构造参数加 `inserters: Inserters | null = null`（可空，与 `belts` 对称）。

帧循环（`BlueprintEditor.vue` / `RenderCore.ts`）：

```ts
const cargoMove = (time % 1000) / 1000;
cargos.cargoMove = cargoMove;
if (belts) belts.cargoMove = cargoMove;
if (inserters) inserters.cargoMove = cargoMove;   // 新增
```

## 6. 着色器注入

**顶点**（`meshlambert_vert`）：

```glsl
// common 之前
uniform float cargoMove;
varying float vArmPhase;
varying float vArmX;
varying float vArmNY;

// begin_vertex 之后
float armLen = 1.0;
#ifdef USE_INSTANCING
    armLen = length(instanceMatrix[2].xyz);   // z 轴缩放 = 臂长
#endif
vArmPhase = (position.z + 0.5) * armLen / INSERTER_ARROW_PERIOD;
vArmX = position.x;
vArmNY = normal.y;
```

**片元**（`meshlambert_frag`）：

```glsl
// common 之前（fragment 必须重复声明 uniform/varying，GL4）
uniform float cargoMove;
uniform vec3 uArrowColor;
varying float vArmPhase;
varying float vArmX;
varying float vArmNY;

// normal_fragment_begin 之后（color_fragment 已过，diffuseColor 可改）
float topMask = step(0.5, vArmNY);
float phase   = fract(vArmPhase + cargoMove);          // + 号，与货物同向
float across  = abs(vArmX) / (INSERTER_BEAM_WIDTH * 0.5);
float slant   = 0.10 + across * 0.26;
float band    = smoothstep(0.06, 0.0, abs(phase - slant));
float edgeFade = smoothstep(0.92, 0.62, across);
float mask    = topMask * band * edgeFade;
diffuseColor.rgb = mix(diffuseColor.rgb, uArrowColor, mask * 0.88);
diffuseColor.a   = mix(diffuseColor.a, 0.95, mask);    // 箭头更实
```

`INSERTER_BEAM_WIDTH` 由模板字符串插值写入（同 v3 GL8），保证加宽时箭头不按旧宽度算。

## 7. 安全要点（新增）

| # | 要点 | 违反后果 |
| --- | --- | --- |
| S16 | `customProgramCacheKey` 三材质互不相同（`dsp-belt-arrow-v2` / cargo / `dsp-inserter-arrow-v1`） | program 串味，箭头逻辑错乱 |
| S17 | 臂长必须从 `instanceMatrix[2]` 提取，**不能**假设 `len` 恒定 | 长臂/短臂箭头密度不一致，或跨实例相位跳变 |
| S18 | `depthWrite: false` 的实例排序限制需在验收中确认；密集场景若不可接受，回退 `depthWrite: true` | 横梁互相遮挡错误 |
| S19 | 透明横梁不改变 `inserterTrans` / `INSERTER_HEIGHT` / `modelRef` 矩阵语义 | 拾取盒与投影错位 |
| S20 | `uArrowColor` 在 `color_fragment` 之后 mix；箭头 alpha 提升不能依赖 `instanceColor` | 箭头被元数据色染暗/染淡 |
| S21 | 加宽只改几何 `x`，实例矩阵无 `x` 缩放 | 箭头 `across` 归一化错误，图案被拉伸 |
| S22 | `inserters` 可空（无分拣器蓝图），帧循环判空 | 空引用崩溃 |
