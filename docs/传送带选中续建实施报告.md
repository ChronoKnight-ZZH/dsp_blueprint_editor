## 2. 阶段 1：传送带节点悬停高亮

- 阶段 6 将单格高亮升级为整条链路高亮（见 §7），单格实现已被取代。

## 3. 阶段 2：点击传送带节点设为 A 点

### 3.1 实现内容

在 `onMouseUp` 的 A 点分支中，按命中对象分三类：

1. **建筑口**：绑定 `beltStartPort`，起点高度 = 口高度，同步 `setBeltZ`。
2. **传送带节点**：记录 `beltArea`（该带所在区域）、精确格坐标（自由角度带保留分数坐标）、`beltStartZ = localOffset[0].z`，并记录 `beltStartBuildingIndex`。末格与中间格都可设为 A 点（提交行为不同，见 §4/§6）。
3. **空白网格**：`materializeTarget` 后以当前建造高度为起点。

`beltStartBuildingIndex` 是 `ref`：高亮覆盖层的 `watchEffect` 要在确认/取消 A 点时立即重算。

### 3.2 状态一览

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `beltStart` | 平面网格点 | 新线路 A 点 |
| `beltStartPort` | `BeltPortEnd \| null` | A 点是否绑定建筑口 |
| `beltStartZ` | number | 起点高度（锁定） |
| `beltStartBuildingIndex` | `Ref<number \| null>` | A 点来源传送带的建筑下标 |
| `beltArea` | `{ areaIndex, origin }` | 本条带所属区域 |
| `placement.beltZ` | number | 终点/建造高度（↑/↓ 调整） |

### 3.3 清理时机

提交成功、右键取消 A 点、退出铺带模式（`watchEffect` 监听 `placement.mode` / `selectedItemId`）。

## 4. 阶段 3：从末格继续铺设并正确连接

- A 点为**末格**（`outputObjIdx < 0`）时，提交走既有 `CreateBeltLineCommand`：按 `occupancyKey`（格 + 高度层）复用末格，`do` 中把末格 `outputObjIdx` 指向新线路首个新增节点，撤销恢复原字段与 yaw。
- 预览、坡度、高度提示全部复用现有实现；起点首段保持水平（`slopeProfile` 规则）。
- 间接测试覆盖：`beltGameConsistency.spec.ts`（接缝格复用 / 撤销恢复）、`beltFreeAngle.spec.ts`（共享整格端点）。

## 5. 阶段 4：中间节点不可直接分叉

- 不变量保持：任何路径都不会产生"两个上游 / 两个下游"。底层由 `CreateBeltLineCommand` 的截断逻辑兜底。
- 阶段 5 落地后，中间格点击不再直接拒绝，而是进入**插入模式**（见 §6）；唯一被拒绝的场景：目标格已把货送入建筑口（插入会切断供料），提示"该传送带已接入建筑口，无法在此插入"。

## 6. 阶段 5：支持从中间节点反向插入（已实现）

### 6.1 拓扑设计

```text
原线路：P → B → C          （B = 被点选的中间格）
插入后：P → B → N2 → … → Nk → C   （绕行：Nk 与 C 相邻）
或      P → B → N2 → … → Nk      （C 被断开，成为新链头，编辑器提示）
```

- 新线路从 B 接出（拖拽方向 = 货物流向），`belts[0]` 就是 B 那一格，命令**复用 B** 不重复入库。
- `do` 改写 B 的输出（B → N2）；Nk 与 C 相邻时接回 C（Nk → C，形成绕行线路），否则断开并提示"已从中间接入：原下游传送带被断开"。
- **B 的上游 P 完全不动**——全线始终唯一上游、唯一下游，无分叉/合流。
- B 与 C 的 yaw 按**实际**上下游平分角重算（`cellYaw`）；撤销恢复双方 yaw 与 B 的输出字段。
- 新线路末端也可以绑定建筑口（光标停在物流站口上）：保留绑定并同步站口方向（`dir = Input`），撤销逐口还原。
- 高度：起点高度 = 目标格高度（`beltStartZ`，首段水平），终点高度 = 建造高度（↑/↓），坡度由 `slopeProfile` 生成；不足的层数按既有规则在起点后第一格垂直堆叠。

### 6.2 命令实现（`src/blueprint/beltLine.ts`）

`InsertBeltLineCommand(belts, target, areaIndex, gridSize)`：

- 校验（先查后写，不产生部分插入）：
  - `belts[0]` 与目标格同格同高度层；
  - 目标必须仍带下游且下游是传送带（送入建筑口的带拒绝插入）；
  - 新增格无占用、未越出纬度带。
- 执行：新增 N2..Nk 入库（分配 index / areaIndex / 扩 `size.x`）→ 串联（`target → N2 → …`）→ 接回或断开 C → 重算 B / C 的 yaw → 同步站口方向。
- 撤销：弹出新增格、恢复 B 的输出字段与 yaw、恢复 C 的 yaw、还原区域宽度、还原站口方向；重做重新接线（重新捕获撤销快照）。

### 6.3 编辑器交互（`src/components/BlueprintEditor.vue`）

- A 点为中间格时正常预览（A → 光标，与末格续建同一套 `buildBeltLine` 参数），预览即所见即所得。
- 提交时按 `beltStartBuildingIndex` 判定插入模式，构造 `InsertBeltLineCommand`；占用/口供料等失败以 `showHint` 提示具体原因。
- 端口高度过滤、坡度、白色六边形预览全部复用，无新增交互算法。

### 6.4 测试（`tests/unit/blueprint/beltInsert.spec.ts`，10 用例）

1. `collectBeltChain`：从中间/链头/末格收集完整链路。
2. `collectBeltChain`：非传送带与越界下标返回空。
3. `collectBeltChain`：断开的线路各自成链。
4. 基本插入：改写目标输出、原下游断开、yaw 重算（B → 45°）、上游不动、撤销/重做。
5. 绕行插入：末端与原下游相邻时接回（C yaw → 135°），撤销恢复。
6. 链头插入：目标无上游也能接出。
7. 拒绝：目标已把货送入建筑口（抛"已接入建筑口"），数据不变。
8. 拒绝：新增格与已有传送带冲突（抛"插入位置已有传送带"，无部分插入）。
9. 拒绝：插入起点与目标格不一致。
10. 坡度插入：光标端高度不同，首段与目标格同高（`[0,0,1,2,2]` 剖面）。

## 7. 阶段 6：整条传送带链路高亮（已实现）

### 7.1 链路收集（`src/blueprint/beltLine.ts`）

新增导出函数 `collectBeltChain(buildings, startIndex)`：

- 沿 `outputObjIdx` 向下游、沿"谁指向我"的反向索引向上游，返回按行进顺序排列的建筑下标（依赖既有不变量 `b.index === 数组下标`）。
- 防环：双向共享访问集；多个上游（非法数据）只认第一个。
- 纯函数、无 Three.js 依赖，可直接单测。

### 7.2 渲染（`src/components/BlueprintEditor.vue`）

- 高亮覆盖层升级为 `InstancedMesh`（容量 `BELT_PREVIEW_CAP`），悬停节点所在**整条链路**每格画一个黄色外圈。
- 优先级：A 点所在链路（拖拽期间保持）> 鼠标悬停链路。
- 场景重建（`b.value` 变化）后自动重算；链路为空或索引失效时不显示。
- 不修改真实传送带材质，不进 library 渲染路径（`dist-lib` 不受影响）。

## 8. 阶段 7：汇入既有传送带（起点 / 中间节点）（已实现）

### 8.1 需求与拓扑

用户图示（B 点落在既有传送带节点上）：

```text
中间：A → B → C → D
              ↑
      E → F → G ┘        （G 指向 C）

起点：A → B → C → D
      ↑
E → F → G ┘              （G 指向 A）
```

规则（用户确认）：

- **目标原线路完全不动**：A→B→C→D 的所有连接字段与 yaw 保持不变；
- 新线路末格 `outputObjIdx` 指向目标节点，因此目标节点可以有**多个上游**（汇入，不是插入/改道）；
- 撤销只删除新线路，不改动目标线路。

### 8.2 实现（`src/blueprint/beltLine.ts`）

`CreateBeltLineCommand` 增加可选第 6 个构造参数 `mergeTarget` 与只读 `merged`：

- `do()` 在"末格终结"处多一个分支：`canMerge()` 通过时把末格输出指向目标
  （`outputObjIdx = target.index`、`outputToSlot = 1`、`outputFromSlot/Offset = 0`），并置 `mergedFlag = true`；
- `canMerge()` 校验：目标仍在蓝图、是传送带、同区域、不在本条路径上、与末格相邻（平面距离 < 1.5 格，`shortArcDelta` 处理经度回绕）；
- 与既有行为的关系：`endPort`（送入建筑口）优先；路径被截断时 `merged === false`，末格照常终结；
- 撤销：新增格弹出、复用格按原快照恢复（含末格可能复用的场景），`mergedFlag` 复位。

### 8.3 编辑器交互（`src/components/BlueprintEditor.vue`）

- 新增 `mergeTargetAt(e)`：光标命中既有传送带时返回汇入目标。拒绝场景：
  - 跨区域；就是 A 点自己；
  - A 点是**中间格**（走 `InsertBeltLineCommand` 的"从该格接出"模式，不在这里叠两种行为）；
  - 从目标沿 `outputObjIdx` 向下游能走回 A 点（会成环）。
- 预览：汇入时路径终点取目标的**精确坐标与高度**（自由角度带是分数坐标），并丢弃目标格本身 —— 末格停在目标旁边、白色连线指向目标；拖拽过程中悬停目标会高亮目标所在链路。
- 提交：构造 `CreateBeltLineCommand(..., mergeTarget)`，`queue.push()` 同步执行后可读 `cmd.merged`，未汇入时提示"汇入失败：末端未能接到目标节点"。
- 高度：终点高度取目标格高度（与口高度覆盖一致），坡度由 `slopeProfile` 生成；末格与目标同高 → 最后一段水平。

### 8.4 测试（`tests/unit/blueprint/beltMerge.spec.ts`，6 用例）

1. 汇入中间节点：原线逐字段不动、目标两条入边、撤销/重做。
2. 汇入起点（链头）：原下游保持。
3. 汇入高度不同：末格停在目标高度，坡度由 z 差表达。
4. 末格不相邻 → `merged === false`，末格照常终结。
5. 跨区域目标 → 不汇入。
6. 目标即末格自己 → 不汇入。

## 9. 遗留问题与风险

| 编号 | 问题 | 影响 | 建议 |

| R1 | 交互未做浏览器端验证 | 高亮位置、点击判定、高层带命中可能有偏差 | 在 `npx serve dist` 中手工验证阶段 1–6 |
| R2 | 计划中的 `beltSelection.spec.ts` 未创建（交互层无组件级单测） | 交互回归依赖手工验证 | 阶段 2–4 数据行为已由 `beltInsert` / `beltGameConsistency` / `beltSlope` 覆盖 |

| R6 | 编码事故 | 中途用 PowerShell 写文件导致中文注释乱码，已从 `HEAD` 恢复 | 备份 stash `corrupted-hover-edits-backup` 已按要求删除 |
| R7 | 汇入是**多上游**拓扑 | 渲染核心按入边集合构建（`incoming: Map<number, BeltLink[]>`），结构上支持；但游戏端是否接受这种蓝图尚未实测 | 导出含汇入的蓝图，在游戏内导入验证；若游戏拒绝，需改为分流器/集装机接入 |
| R8 | 多条入边时链路高亮只认一个上游 | `collectBeltChain` 的反向索引每个节点只记第一个上游，汇入线路的另一支不高亮 | 预览/高亮阶段可扩展为多上游集合 |
| R9 | 汇入目标的识别依赖 BVH 命中 | 高层带/被遮挡时的命中偏差会落到相邻格 | 与阶段 1 同一风险，实测后可加传送带专用拾取 |
